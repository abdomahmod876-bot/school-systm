# School Management System (C++)

## Overview
This project is a simple School Management System developed using C++ and Object-Oriented Programming (OOP).  
The system allows managing different parts of a school such as students, teachers, staff, courses, classrooms, and exams.

## Features
The system provides a console-based menu that allows the user to:

- Add Students
- Add Teachers
- Add Staff
- Add Courses
- Add Classrooms
- Add Exams
- View all stored data

## System Structure
The project is designed using OOP principles where each entity in the school is represented by a class.

Main classes used in the project:

- Person
- Student
- Teacher
- Staff
- Course
- Classroom
- Exam
- School

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- Console Application

## Project Goal
The goal of this project is to practice OOP concepts such as:
- Classes
- Encapsulation
- Inheritance
- Object interaction
- Data management using vectors
